# Movie Ticket Booking System — Flat Student Version

This is the same project, but simplified for class/assignment use.

## Structure
All Java files are in one folder.
No `src`, no `com.example...` package structure.

## Compile
```bash
javac *.java
```

## Run
```bash
java Main
```

## Notes
- Role is inside `User`
- No display strategy interface
- Admin can create movie, theatre, and show from the system
- Supports booking, cancellation, payment, refund, seat types, and simple rule-based pricing
